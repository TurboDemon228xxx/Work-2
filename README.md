# Практическая работа № 2 · Вариант 26

CLI для анализа прямых и транзитивных зависимостей Python-пакетов.
Программа читает `requires_dist` выбранного выпуска через JSON API PyPI
с помощью `urllib`. Библиотека `packaging` разбирает PEP 440 и PEP 508,
проверяя ограничения версий и маркеры окружения. Граф строится
рекурсивным BFS по уровням. Каждый узел посещается один раз, рёбра
циклов сохраняются. Pillow рисует PNG по тем же узлам и рёбрам.

## Установка и запуск

Нужен Python 3.10 или новее. В корне репозитория выполните команды:

```shell
python -m pip install -r requirements.txt
python -m src examples/requests.json
python -m unittest discover -s tests -v
```

В Windows можно использовать `.\run.bat examples/requests.json`,
в Linux и macOS — `sh run.sh examples/requests.json`.
Переменная `WORK2_PYTHON` задаёт путь к интерпретатору для этих скриптов.
Для тестов и локальных примеров соединение с PyPI не требуется.

## Конфигурация JSON

| Ключ | Значение |
| --- | --- |
| `package` | Имя пакета PyPI или имя из латинских заглавных букв в тестовом режиме. |
| `repository` | Базовый URL PyPI JSON API или путь к локальному JSON со списками смежности. |
| `test_mode` | `true` использует локальный граф, `false` запрашивает PyPI. |
| `version` | Версия корневого пакета по PEP 440. В локальном графе версии не используются. |
| `graph_image` | Путь к PNG. Рядом сохраняется файл Mermaid с расширением `.mmd`. |
| `ascii_tree` | `true` выводит ASCII-дерево при сохранении графа. |
| `filter_substring` | Исключает зависимости, содержащие подстроку без учёта регистра. Пустая строка отключает фильтр. |

Относительные пути считаются от каталога конфигурации. Корневой узел
сохраняется даже при совпадении с фильтром. Некорректная конфигурация
завершает программу с кодом 1 и сообщением об ошибке.

Локальный репозиторий представляет собой объект вида
`{"A": ["B", "C"], "B": [], "C": ["A"]}`. Ключи задают все узлы,
поэтому у пакетов без зависимостей указан пустой список.

## Режимы и примеры

| Режим | Операция |
| --- | --- |
| Без флага | Записывает Mermaid и PNG. При включённом `ascii_tree` печатает дерево. |
| `--show-config` | Показывает настройки в формате `ключ=значение`. |
| `--direct` | Печатает требования корневого выпуска или его прямых соседей в тестовом графе. |
| `--graph` | Печатает списки смежности в порядке BFS с учётом фильтра. |
| `--order` | Печатает зависимости перед зависящими пакетами. Циклические рёбра отмечаются в stderr. |

```shell
python -m src examples/requests.json --show-config
python -m src examples/requests.json --direct
python -m src examples/test-cycle.json --graph
python -m src examples/test-filter.json --order
python -m src examples/httpx.json
python -m src examples/jinja2.json
```

В ASCII-дереве `(cycle)` обозначает переход к предку, `(shared)` —
зависимость, уже раскрытую в другой ветке. Демонстрации трёх графов
и фактическое сравнение с pip приведены в [pract.md](pract.md).

## Особенности анализа

Для каждого требования выбирается самый свежий доступный выпуск,
удовлетворяющий ограничению версии и `Requires-Python`. CLI учитывает
маркеры текущей платформы и extras, запрошенные зависимостями.
Выбор производится для каждого ребра отдельно. pip дополнительно
согласует версии для всех требований, учитывает теги wheel и может
вернуться к более раннему варианту при конфликте. Из-за этого на
сложных графах версии или состав пакетов могут отличаться. Прямые
ссылки на архивы и VCS в требованиях завершаются явной ошибкой.

[Описание PyPI JSON API](https://docs.pypi.org/api/json/#get-a-release)
